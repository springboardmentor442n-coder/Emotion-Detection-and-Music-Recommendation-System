# 🎵 Emotion Detection and Music Recommendation System

## 📌 Project Overview

This project is a web-based application that detects human emotions from facial expressions and recommends music based on the identified mood. It combines deep learning with an interactive user interface to deliver a personalized experience.

---

## 🚀 Features

- 🎭 Real-time Emotion Detection using CNN
- 📷 Supports image and text-based input
- 🎶 Music Recommendation based on detected emotion
- 🌐 Interactive web interface using HTML, CSS, and JavaScript

---

## 🧠 Technologies Used

- Python
- Flask
- TensorFlow / Keras
- OpenCV
- HTML, CSS, JavaScript
